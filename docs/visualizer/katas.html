LEVEL 1 · THE WARMUP

Fixed 3-Arity Sum

sum3(1)(2)(3) === 6

Tests basic nested closure returns. Every returned function closes over the prior scope variables until the final invocation returns the accumulated value.

LEVEL 2 · OA DRILL

Infinite Currying with Empty Terminator

infiniteSum(1)(2)(3)() === 6

Common in Mettl/TCS/Accenture screenings. Checks whether args.length === 0 to break the recursive closure chain and return the sum.

LEVEL 3 · COERCION TRAP

Infinite Chaining via valueOf

add(1)(2)(3) + 4 === 10

Advanced JS trick: Overriding Function.prototype.valueOf or Symbol.toPrimitive so that the returned function coerces into a number in arithmetic operations without an empty call.

LEVEL 4 · MACHINE CODING

Universal curry(fn) Implementation

curry(fn)(1, 2)(3) === fn(1, 2, 3)

The universal higher-order function that powers functional pipelines. Compares accumulated args.length >= fn.length; returns curried wrapper or invokes fn.

LEVEL 5 · STAFF LEVEL

Placeholder Curry (Lodash _ Style)

curriedSub(_, 2)(5, 1) === 2

Supports supplying arguments out-of-order using a placeholder symbol. Replaces placeholders as later arguments arrive in the accumulator.

COMPARISON

Currying vs Partial Application

f(a,b,c) ➔ f(a)(b)(c) vs f(a)(b,c)

Currying strictly produces unary function chains (1 arg per call). Partial application fixes a subset of arguments now, returning a function accepting all remaining arguments at once.

🧠 Mettl OA MCQ Practice Bank (Arity & Length Traps)
function f1(a, b = 2, c) {}; console.log(f1.length);
Answer: 1

Rule: fn.length stops counting parameters the moment it hits the FIRST parameter with a default value (b = 2).

function f2(a, ...rest) {}; console.log(f2.length);
Answer: 1

Rule: Rest parameters (...rest) are never counted in fn.length.
